# DIALOGUE-GAME
Mobile game for winning arguments, debates, # MOBILE GAME

A fast-paced pixel-art conversational strategy game built for iPhone.

Players control an anthropomorphic rabbit in high-stakes conversations
against bosses, dates, teachers, rivals, and other characters.

The player's words are the weapon.

## Core Gameplay

- Type responses using the iPhone keyboard
- AI-powered NPC conversations
- Use conversational tactics
- Gain or lose confidence, charm, logic, and control
- Win short 1–3 minute encounters
- Unlock new characters, scenarios, tactics, and cosmetics

## First Vertical Slice

Rabbit vs. Boss

Objective:
Convince your boss not to fire you.

## Technology

- Godot 4
- GDScript
- iOS first
- Backend AI conversation service
- Android/Web later
